## 二、作品亮点

### 2.1 主闭环：六维画像驱动完整学习链路

- 学生首次使用即通过对话式采集建立六维认知画像（专业背景、前置知识、认知风格、易错倾向、学习目标、时间弹性），后续学习事件持续刷新。
- 多智能体协同（Coordinator + Doc/Mind/Quiz/Read/Media/Code Agent）一次生成 6 类资源，SSE 流式推送过程可视化。
- 画像驱动个性化学习路径，评估后可一键回灌重排。
- 苏格拉底追问与费曼讲解双模式智能辅导，Tutor 结构化评分并回写画像。
- 雷达图/掌握度/阶段对比等效果评估，形成采集→生成→验证→反馈闭环。

**证明**：见附录 C.1–C.4（资源 5 案例 / 路径 3 案例 / 辅导 3 段 / 评估 1 份）。

### 2.2 幻觉防控：Shield 三级防线

- **一级**：出题携带知识点 ID 与期望要点，RAG 绑定校本依据。
- **二级**：Evaluator 独立产出引用 ID 与置信度，交叉验证。
- **三级**：低置信、引用不一致或逻辑矛盾自动转入教师待人审工单，不以低置信结果为权威终裁。

**证明**：见附录 C.5（H1 低置信工单截图，教师端可复核）。

### 2.3 四闸门禁掌握协议（挑战赛增量）

区别于传统「答对 2/3 选择题即点亮」，引入学→练→讲→用四级闸门：

- **学闸**：需完成学习证据（观看演武/阅读教材/生成资源/记笔记）方可进入练习。
- **练闸**：综合小测 5 题（概念+辨析+应用混合），正确率 ≥80% 且核心标签无连续错误。
- **讲闸**：强制费曼讲解，Tutor 结构化评分及格才通过；可先由数字人示范。
- **用闸**：代码类行星需 CodeLab 微习题通过；纯概念行星可豁免。

搭配记忆衰减与班级 GatePolicy，使点亮真正代表「学会了」。

**证明**：见附录 D.1（四闸门禁行星面板截图 + 进度步骤条）。

### 2.4 演武舱 AlgoVizLab（挑战赛增量）

BFS/DFS/Dijkstra 算法步进可视化，支持暂停、单步、回退。AI 可根据自然语言描述（如「演示红黑树旋转」）动态生成轨迹 JSON 并实时播放。交互模式下允许修改初始数据后重跑算法，即时对比结果变化。

**证明**：见附录 D.2（BFS/DFS 演武截图 + AI 生成轨迹界面）。

### 2.5 星库中枢与双模式伴学（挑战赛增量）

内置 PDF 阅读器，支持原文划词提问（「问伴学」）与加入知识库笔记。双模式切换：

- **原书模式**：AI 推荐 B 站相关视频，拓展阅读。
- **考研讲义模式**：加载本地高质量 MP4，支持知识点打点定位。

使教材从「静态 PDF」变为「动态学习上下文」。

**证明**：见附录 D.3（星库划词 + 双模式切换截图）。

### 2.6 数字人、代码舱与自习督导（挑战赛增量）

- **数字人**：集成讯飞虚拟人，学生可请求「请数字人讲一遍」，通识视频播放 + 错题分镜讲解。
- **代码舱 CodeLab**：沙箱化 Python/JavaScript 在线执行，提交后显示服务端运行结果。
- **自习督导**：TensorFlow.js + COCO-SSD 本地摄像头推理，检测分心行为并记录专注热力图，数据不出浏览器。

**证明**：见附录 D.4–D.6（数字人面板 / 代码舱运行结果 / 自习督导热力图）。

### 2.7 工程落地与可复现性

- Docker Compose 一键部署（MySQL + Backend + Frontend + Codelab-Runner），评委侧零环境摩擦。
- 公网 HTTPS 部署 `https://wikj.online`，可随时访问验证。
- 完整软件工程文档 16 份（A–G 国标准则），覆盖可行性、需求、设计、实现、测试、运维全生命周期。
- 多模型路由（DeepSeek / 讯飞 / 火山方舟 Seedance / 豆包 / 通义），API 成本可控（全周期约 350 元）。
