## 1. 竞赛作品评分表 — 分项自评

满分结构：**基础 100 + 附加 10 = 110**。下表为对照仓库与部署现状的**队内自评预估**（非官方终评）。

| 序号 | 评审要点 | 满分 | 自评 | 主要依据 / 扣分点 |
|------|----------|------|------|-------------------|
| 1.1 | 功能实用性（多角色、云部署、交互合理） | 10 | **8.5** | 三角色完整；已上云 HTTPS；纯 Web 无原生多端，略扣 |
| 1.2 | 方案创新性（闭环、费曼/苏格拉底、幻觉防控） | 15 | **13.5** | 四闸闭环、镜像预演、费曼/苏格拉底、教师低置信工单 |
| 1.3 | 技术创新性（多智能体、多模态、选型对比） | 10 | **8.5** | LangGraph + 多 Agent、Seedance、RAG；有选型对比；多端弱 |
| **1 小计** | 创新价值与实用性 | **35** | **30.5** | |
| 2.1 | 系统完善度（采集→生成→验证→反馈全流程） | 10 | **9.0** | 画像/资源/路径/辅导/评估链路有实现锚点 |
| 2.2.1 | 对话式六维画像 | 8 | **7.5** | 六维 + 更新能力已实现；证据截图需可演示 |
| 2.2.2 | ≥5 类资源生成 + 案例 + 质量评估 | 10 | **9.0** | ≥6–7 类 + 质量评分；案例表已有，部分截图槽位未补 |
| 2.2.3 | 个性化路径与推送（3–5 案例） | 3 | **2.7** | 路径前后对比约 3 条 |
| 2.2.4 | 智能辅导（加分项） | 5 | **4.5** | 苏格拉底/费曼/数字人；tutor 案例 5 段 |
| 2.2.5 | 学习效果评估（加分项） | 5 | **4.0** | 雷达/掌握度有；评估案例建议补满 3 份 |
| 2.3 | 功能创新（数字人等拓展） | 5 | **4.8** | 数字人、演武舱、代码沙箱、自习督导、星库等 |
| **2 小计** | 功能实现及技术要求 | **45** | **41.5** | |
| 3 | 配套文档丰富度 | 10 | **7.5** | 设计/部署/证据包强；缺国标分册形态 SRS/测试专册；截图未齐 |
| 4 | 演示视频、PPT | 10 | **6.0** | 脚本齐全；录屏与终版 PPT 证据清单未勾完 |
| **基础合计** | | **100** | **约 85.5** | |
| 5.1 | 附加分（讯飞、私有库、幻觉防控、可扩展等） | 10 | **8.5** | 讯飞全家桶、Chroma/Vault、Shield、OpenAPI、国产模型；软硬结合弱 |
| **总计** | | **110** | **约 94 / 110** | 折合百分制约 **85–88**（视频/PPT 补齐后可冲 **90+**） |

### 1.1 冲高分优先缺口

1. 补齐录屏（系统演示 ≥60%）与低 AI 味 PPT → 抬高第 4 项  
2. 补齐证据截图（deck / media 溯源 / eval×3 / 演武）→ 稳住 2.2 与第 3 项  
3. 将现有设计方案拆/补成「国标文档套」→ 抬高第 3 项并满足软工规范
