# 答辩 60 秒话术（含休闲/社交 10 秒带过）

## 时间纪律（整场演示）

| 内容 | 上限 |
|------|------|
| 画像→资源→路径→苏格拉底/费曼→评估→教师工单 | ≥70% |
| 架构/防幻觉说明 | ~20% |
| 休闲区/桌宠/树洞/小游戏 | **≤10%（约 10 秒）** |

## 主闭环（约 50 秒）

「SparkOrbit 做的是高等教育个性化学习闭环：对话建六维画像 → 多智能体生成六类资源（含已开通的 Seedance 1.0 Pro Fast 教学短视频与质量评分）→ 按画像推路径 → 苏格拉底/费曼辅导 → 雷达评估并可一键回灌重排路径；低置信或矛盾判题进教师工单。防幻觉靠 Evaluator 独立引用知识点 ID、RAG 校本依据和人审。」

## 评委问「小游戏 / 桌宠 / 树洞？」→ 10 秒带过

「休闲与社交是激励与情绪留存的体验增强，**不是赛题评分主链路**。主分看画像—资源—路径—辅导—评估；我们把时间留给闭环演示。」  
（说完立刻切回资源工坊或教师工单画面，不要点开游戏。）

## 评委问「真视频 / 多模态资源？」

「已开通火山方舟 Seedance 1.0 Pro Fast，MediaAgent 经推理接入点生成短视频并落盘可播；失败才降级 GSAP 分镜或本地缓存。现场可看 provider=seedance 与质量评分卡。」

## 评委问「费曼学习法？」

「行星面板勾选费曼模式：学生先用自己的话讲解，Tutor 挑漏洞并追问，讲解事件回写画像。与默认苏格拉底模式可切换对比演示。」

## 评委问「幻觉互锁？」

「已实现：出题带知识点 ID 与期望要点；Evaluator 独立产出引用 ID 与置信度；低置信、引用不一致或逻辑矛盾转教师待人审，不以低置信结果作权威终裁。现场可演示强制低置信工单。」
