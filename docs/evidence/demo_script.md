## 二、旁白要点（细则见提词稿）

**开场定位：** 不是聊天框，是一条教育 Agent 闭环；一句话点三大断层（同质课件 / 聊天甩答案 / 低置信当终裁）。

**数据边界：** 登录页硬说一句「全程演示/模拟数据，非真实学籍」。

**八维画像：** 专业背景 / 前置知识 / 认知风格 / 易错倾向 / 学习目标 / 时间弹性 / 资源模态偏好 / 学习动机强度；演示对话需覆盖模态与动机两句。

**资源工坊：** Coordinator 调度多类 Agent；Seedance 真播放 8–10 秒；质量分（准/贴画像/完整/幻觉）；不说「超过五种」软杯话术。

**四闸：** 学练讲用才算掌握，不是答对几题。

**学闸证据：** 星库划词问伴学 → 剪藏进星轨知识库（行星到全局三级双链笔记，Markdown/Obsidian 双链）→ 演武步进 → 代码舱测例。

**辅导：** 苏格拉底先问后讲、给依据来源，不直接给答案（对应赛题 FAQ Q12）；费曼讲闸结构化评分。

**低置信：** 出题/判题分开；知识点 ID + 置信度 + 待人审；不当终裁。

**自习区（讲细）：** 选房 → 计时 → 白噪音 → 摄像头**本地 TF.js 推理**检测手机/离座，**每几秒同步一张低清静帧给教师巡查、关掉即清空**，不做连续录像 → 排行。强调「最小化使用 + 可删除」合规点。

**教师端：** 办结工单 = 人审终裁，不替代教师；备课/锻造压成一句。

**管理端：** Agent 运行回放（workflow / handoff 步骤按 user_id 回放）= 输出可追溯；Token/维护扫一眼。

**多模态语音出口：** 星际通讯舱（四级/六级/雅思/粤语口语舱，录音转写 + 发音评测三项 + 教练点评，可文字降级）+ 模拟面试（第 7 区，准备 / 单轮 / 三官总评，弱项回流错题）；两者共用同一套语音能力，关麦可文本降级。

**一带而过：** 星域 / 桌宠 / 树洞 / 聊天（各 8–10 秒）；桌宠永不展开玩。
