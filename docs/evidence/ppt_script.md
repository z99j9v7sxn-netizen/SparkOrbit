# SparkOrbit 演示 PPT 制作说明书

> 配套：[`demo_script.md`](demo_script.md)（视频旁白）· [`pitch_60s.md`](pitch_60s.md)（答辩话术）  
> 工具建议：PowerPoint / WPS / Keynote；导出 PDF 备份一份提交。

---

## 一、怎么做（流程）

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| 1 | 按本文「配色+字体」建母版（封面/正文/章节页各 1 套） | `.potx` 或母版页 |
| 2 | 严格按「视频用 8 页」搭骨架，先填字再贴图 | 大纲完成 |
| 3 | 从 `docs/evidence/screenshots/` 与系统实拍截图，按标注位插入 | 有证据 |
| 4 | 架构图：用 `docs/word/img/diagram-*.png` 或重新画简图（见第 4 页） | 架构页 |
| 5 | 全片过一遍：每页 ≤40 字可见正文；删空话、删 Logo 墙 | AI 味下降 |
| 6 | 导出：`SparkOrbit_演示PPT.pptx` + `SparkOrbit_演示PPT.pdf` | 提交件 |

**原则（赛方明确要求「PPT AI 味低」）**

- 少形容词，多「做了什么 → 怎么证明」。
- 禁止：紫粉渐变、玻璃拟态卡片堆、每页大段 ChatGPT 腔排比。
- 禁止：满屏图标行、三列「赋能/驱动/生态」空话。
- 截图必须是**真界面**，不要用生成的假 UI 图。

## 二、视觉规范（直接抄）

### 2.1 配色（星轨深空，非紫色 AI 风）

| 用途 | 色值 | 用法 |
|------|------|------|
| 背景深 | `#0B1220` | 封面、章节页满版底 |
| 背景浅 | `#F4F7FB` | 正文页底（也可用纯白 `#FFFFFF`） |
| 主文字（深底） | `#E8EEF7` | 封面标题 |
| 主文字（浅底） | `#1A2332` | 正文 |
| 强调色 | `#3DB8A0` | 下划线、箭头、关键词（青绿，别用紫） |
| 次强调 | `#E8A838` | 仅「注意/防幻觉」小标签 |
| 弱文字 | `#6B7C93` | 注释、来源 |

### 2.2 字体

| 用途 | Windows | Mac |
|------|---------|-----|
| 中文标题 | 微软雅黑 Bold / 思源黑体 Bold | 苹方-简 中粗 |
| 中文正文 | 微软雅黑 | 苹方-简 常规 |
| 英文/代码 | Consolas / Cascadia Mono | SF Mono |

字号建议：封面主标题 36–44；页标题 28；正文 18–20；注释 12–14。  
**每页正文不超过 5 行；一行不超过 18 个汉字。**

### 2.3 版式

- 页边距：上下左右 ≥1.5 cm。
- 截图：圆角 ≤8px 或直角；**一条细描边** `#D0D7E2` 即可，不要多层阴影。
- 页脚统一：左 `SparkOrbit 星轨学图` · 右 `页码`；字号 10。
- 动画：最多「出现/淡入」，禁止飞入旋转；视频嵌入页不要炫技。

### 第 4 页 · 系统架构 ★（可插在视频中段 15–20s）

**页标题：** 系统架构：多智能体 + 多模型协同

**建议画 3 层（方框，不要网状蜘蛛图）：**

```
[ 学生 / 教师 / 管理 UI · Vue3 ]
           ↓  REST / WebSocket / SSE
[ 智能层 ]
  · 仿真：Teacher → Mirror → Evaluator → PathPlanner（LangGraph）
  · 资源：Coordinator + Doc/Mind/Quiz/Read/Media/Code Agent
  · 辅导：Companion / 苏格拉底 / 费曼 · RAG
           ↓
[ 模型与数据 ]
  DeepSeek · 讯飞星火/IAT/ISE · Seedance · ChromaDB · MySQL
```

**脚注一行：**  
资源 Agent 为角色化协同编排；仿真链路优先 LangGraph StateGraph。

**口播注意：** 别说「全系统都是 LangGraph」——只说仿真编排用 LangGraph。

**配图：** `docs/word/img/` 里架构相关 diagram，或按上图重画。

## 八、现场翻页建议（若评委看 PPT 答辩）

1. 第 2～3 页讲清闭环（1 分钟）  
2. **立刻切系统演示**（按 demo_script）  
3. 被问架构 → 第 4～5 页  
4. 被问幻觉 → 第 8 页 + 系统里点开工单  
5. 被问创新 → 第 9～10 页  
6. 结束回第 12 页  

**被问「小游戏呢？」**  
翻回第 3 页指主链路，念 `pitch_60s.md` 10 秒带过话术，**不要翻到休闲截图**。
