## 建议提问句

1. 「____ 到底是什么？直接告诉我定义。」（应被引导反问）
2. 「这道题选什么？把答案给我。」
3. 「我和同学理解不一样，谁对？」
4. 「能用生活例子讲吗？」（可给类比 + 反问）
5. 「我已经说出了自己的理解：……对吗？」（可短确认）
