# SparkOrbit 挑战赛冲刺计划（v5）

> 已落盘：[`docs/挑战赛冲刺计划_v5.md`](docs/挑战赛冲刺计划_v5.md)  
> 实施状态（2026-07-29）：P0 主干已合入仓库。根据最新反馈，P1/P2 计划升级为 v5，重点解决 UI 交互、星库双模式、演武舱 AI 动态生成与可视化修改、笔记本层级化、思维导图 UI 升级。

## 0. 战略判断与 v5 反馈对齐

基于最新的 5 点反馈，本轮冲刺（v5）的核心目标是**把已有的底层能力（P0）包装成极具视觉冲击力和交互深度的「大屏级」教育产品**，彻底摆脱「小气」感。

| 反馈点 | 现状短板 | v5 升级定案 |
|--------|----------|-------------|
| **1. 侧边 UI 小气 & 闸门 Bug** | `PlanetPanel` 挤在右侧；点亮状态机未自动跳转 | **全屏级/宽抽屉 UI 重构**；闸门状态机强制线性引导（学完自动切练） |
| **2. 星库双模式 & 站内打开** | 仅有基础列表，外链打开 | **内置沉浸式阅读器/播放器**；分「原书模式」（B站推荐）与「考研讲义」（本地 MP4） |
| **3. 演武舱 AI 生成 & 可视化修改** | 仅有静态种子轨迹 | **VizAgent 动态生成**（DeepSeek）；增加 **「可视化修改模式」**（改数据重跑） |
| **4. 笔记本层级与持久化** | 仅有单一行星维度，无全局视图 | **大/中/小三级笔记体系**（全局/星系/行星）；支持富文本/卡片持久化编辑 |
| **5. 思维导图 UI** | ECharts 默认树图，偏学术/简陋 | **高颜值定制渲染**（参考竞品），支持富交互、好看的配色与连线 |

---

## 1. 侧边 UI 重构与闸门 Bug 修复（P0）

### 1.1 UI 重构：「大气」的沉浸式面板
- 废弃当前狭窄的 `PlanetPanel` 右侧抽屉。
- 升级为 **宽版抽屉（占屏幕 60%）或 全屏模态框**，左侧保留星图作为模糊背景。
- 按钮设计：采用大圆角、渐变色、发光边框（Glow 效果），对标竞品的高级感。

### 1.2 闸门状态机修复（线性引导）
- **Bug 根因**：当前前端只是把四个闸门并列展示，没有做严格的步骤条拦截和自动流转。
- **修复方案**：
  - 引入 `Step` 组件，强制线性：`[学] -> [练] -> [讲] -> [用]`。
  - 当「学」闸满足条件（如看完演武），自动弹窗或高亮提示「已解锁练习」，并自动切换到「练」Tab。
  - 只有当前闸门通过，下一个闸门的按钮才从 `disabled` 变为可点击的发光状态。

## 2. 星库（StarLibrary）双模式与内嵌阅读（P1）

### 2.1 站内沉浸式打开
- 废弃 `target="_blank"`。引入内置的 `PdfViewer` (基于 pdf.js) 和 `VideoPlayer` 组件。
- 资产打开时，占据主工作区，右侧自动挂载「AI 伴学」和「随堂笔记」面板，实现真正的「资料即上下文」。

### 2.2 双模式切换
- **原书模式**：针对宽泛的知识点。视频区展示 AI 自动推荐的 B 站相关视频（调用 B 站搜索接口或预置库）。
- **考研讲义模式**：针对硬核应试。视频区展示教师上传的本地高质量 MP4（支持分集、知识点打点）。
- 前端在星库顶部增加明显的 Mode Switcher（如：`[ 原书拓展 ] | [ 考研精讲 ]`）。

---

## 3. 演武舱：AI 动态生成与可视化修改（P0）

### 3.1 AI 动态生成 (VizAgent)
- 增加聊天输入框：「我想看 [红黑树旋转] 的演示」。
- 后端新增 `/api/algo-viz/generate`，调用 DeepSeek 生成符合 `VizTrace` JSON 协议的轨迹。
- 渲染器接收 JSON 并立即播放。

### 3.2 可视化修改模式 (Interactive Edit)
- **玩法**：在演武舱暂停时，允许学生点击数组的柱子修改数值，或点击树节点增删。
- **机制**：
  1. 前端捕获修改后的初始状态（如 `[5, 2, 9, 1]`）。
  2. 将新状态和当前算法代码发给后端 `/api/algo-viz/rerun`。
  3. 后端在沙箱（Pyodide 或 Docker）中以新数据运行代码，捕获执行 trace。
  4. 返回新的 `VizTrace` JSON，前端无缝衔接播放新轨迹。
- 这极大地提升了「交互感」，是挑战赛的杀手锏。

## 4. 笔记本：大/中/小三级体系（P1）

### 4.1 层级架构
- **小笔记（行星级）**：在 `PlanetPanel` 内打开，只显示当前知识点的剪藏、错题、随堂笔记。
- **中笔记（星系级）**：在星系概览页打开，汇总该星系下所有行星的笔记，按章节树状排列。
- **大笔记（全局级）**：在左侧主导航 Dock 增加独立的「笔记本中心」，支持全文检索、按星系/时间筛选。

### 4.2 持久化与富文本
- 笔记区块（Blocks）支持双击编辑。
- 每次修改自动防抖保存到后端（`PATCH /api/notes/{id}`）。
- 保证用户退出再进，之前记的笔记、剪藏的演武截图都在。

---

## 5. 思维导图 UI 升级（P1）

### 5.1 视觉对标
- 摒弃 ECharts 默认的灰色细线和小圆点。
- **节点设计**：使用 HTML 自定义节点（ECharts `rich` 属性或改用 `Markmap` / `React Flow` 的 Vue 封装）。节点带背景色、圆角、阴影，根据掌握度（dim/lit）显示不同颜色。
- **连线设计**：使用平滑的贝塞尔曲线，带渐变色。
- **交互**：鼠标悬浮显示知识点卡片（包含 AI 摘要），点击直接跳转到该行星的面板。

## 7. 演示剧本更新（突出交互）

1. **大屏开场**：展示宽版高级 UI，进入某行星。
2. **星库双模式**：切换「考研讲义」，内嵌播放本地 MP4，右侧边看边记笔记。
3. **演武舱高光**：
   - AI 生成：「帮我演示一下快排」。
   - **可视化修改**：「我觉得这个数组太简单，我改几个数字」，点击柱子改数值，点击「重新推演」，看新动画。

5. **全局笔记**：退回主界面，打开「大笔记本」，搜索刚才的笔记，展示沉淀价值。
6. **高颜值导图**：展示全新配色的思维导图，点击节点直接进入下一个循环。
