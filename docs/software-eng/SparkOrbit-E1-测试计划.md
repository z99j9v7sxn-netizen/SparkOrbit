## 2 计划

### 2.1 软件说明

SparkOrbit 星轨学图是基于多智能体协同的高等教育个性化学习平台，采用 Vue 3 + FastAPI + LangGraph 技术栈，Docker Compose 一键部署。测试环境含公网（https://wikj.online）与本地 Docker 两种模式。

### 2.2 测试环境配置

| 项 | 配置 |
|----|------|
| 操作系统 | Windows 11 / macOS Sonoma |
| 浏览器 | Chrome 126+, Edge 126+ |
| Docker | Docker Desktop 4.30+ |
| MySQL | 8.0（Docker 容器，端口 3306） |
| Backend | FastAPI + Uvicorn（容器端口 8000） |
| Frontend | Nginx + Vue 3 SPA（容器端口 80） |
| Codelab Runner | Python 子进程（sidecar） |

**API Key 配置要求**（`.env` 文件）：

| 变量 | 必需 | 用途 |
|------|------|------|
| `DEEPSEEK_API_KEY` | 是 | 核心 LLM（画像/资源/路径/辅导） |
| `SPARK_APP_ID` / `SPARK_API_KEY` / `SPARK_API_SECRET` | 推荐 | 讯飞语音/数字人 |
| `VOLCANO_ARK_API_KEY` | 推荐 | Seedance 视频生成 |
| `DOUBAO_API_KEY` | 可选 | 幻觉交叉验证第二模型 |

### 2.3 测试数据准备

| 数据项 | 准备方式 | 说明 |
|--------|----------|------|
| 演示账号 | 系统 seed 脚本自动创建 | student001/teacher001/admin001 |
| 课程数据 | 预置种子数据 | 计算机基础/数据结构/高等数学 |
| 教材 PDF | `star_assets` 表引用 | 《计算机网络》《高等数学》 |
| 挑战题库 | 与行星关联 | 每行星 >=3 道挑战题 |

## 4 测试设计说明

### 4.1 测试控制

| 测试族 | 启动条件 | 停止条件 |
|--------|----------|----------|
| T1-T6 | Docker 环境就绪 + API Key 已配置 | 全部用例执行完毕或关键缺陷阻塞 |
| T7 | 安装包解压完毕 | 全部用例执行完毕 |
| T8-T11 | 面试/求职/教师审阅/考级功能就绪 | 全部用例执行完毕 |

### 4.2 测试执行流程

```
环境检查 → 数据准备 → 按族执行（T7→T1→T2→T3→T4→T5→T6）→ 缺陷记录 → 回归验证 → 报告输出
```

T7 优先执行以确认环境可用，后续按功能依赖关系展开。

## 5 评价准则

### 5.1 通过标准

- 关键路径（T7 部署→T1 画像→T2 资源→T5 评估）100% 通过
- 其余用例功能正确率 >=95%
- 无 P0 阻塞缺陷

### 5.2 暂停/恢复标准

| 暂停条件 | 处理方式 |
|----------|----------|
| 关键缺陷阻塞核心流程 | 暂停测试，修复后恢复 |
| AI 服务不可用 | 记录降级行为，不阻塞测试 |
| Docker 环境异常 | 暂停测试，重建环境后恢复 |

### 5.3 测试完成标准

- 全部 54 个用例执行完毕
- 缺陷全部记录并分类
- E2 测试分析报告已输出
