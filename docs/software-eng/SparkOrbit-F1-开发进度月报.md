## 3 第二期：国赛闭环冲刺（2026-07-13～07-20）

> 本期是开发最密集的一周。利用高强度 AI 辅助冲刺，国赛规定功能闭环在约 5 天内从零搭通，并交付可运行代码包与证据材料。

### 3.1 进度与状态

| 日期 | 主要完成事项 |
|------|-------------|
| **07-13** | MySQL 8.0 切换；星系/行星/点亮模型落库；OrbitExplorer 3D 星图（Three.js）；Teacher + Companion 对话入口；课程种子数据 |
| **07-14** | GSAP + Three.js 渲染调优；错题本、成长报告、知识图谱等学习区组件集中创建（当日前端新增约 60 个文件） |
| **07-15** | Production-Grade 视觉升级；`backend/app/` 大批量落盘（约 85 个文件）：shield.py / challenge.py / note_service 等 |
| **07-16** | 教师端重构；`resource_agents.py` 多智能体编排；ResourceStudio 资源工坊前端；学习路径面板；`docs/作品设计实现方案.md` |
| **07-17** | 证据包整理：`docs/evidence/`（demo_script.md / eval_cases / resource_cases / tutor_cases / path_cases + screenshots） |
| **07-18** | Docker 一键部署包：`docker-compose.yml` + `start.bat/sh` + `部署说明书.md`；录屏脚本/PPT 脚本 |
| **07-19～20** | Seedance 视频通路补全；PPT 相关材料收口 |

**本期核心成果**：画像→资源→路径→辅导→评估的国赛闭环全部打通，形成可提交参赛包（后获**全国三等奖**）。

### 3.2 资源耗用

| 资源 | 耗用 |
|------|------|
| 开发工时 | 约 120 人时（高强度 AI 辅助冲刺） |
| 云主机 | 腾讯云轻量 2C4G（07-18 开通） |
| AI API | DeepSeek/豆包/讯飞 约 300K tokens（功能开发与调优） |
| 域名 | wikj.online 注册与配置 |

### 3.3 下期计划

- 等国赛结果
- 如需继续参赛，补挑战赛加分项（四闸、演武舱、星库、数字人、代码舱等）
