## 1 引言

### 1.1 编写目的

本手册为 SparkOrbit 星轨学图的学生、教师、管理员三种角色用户提供完整的操作指南，覆盖从登录注册到各类功能使用的全部场景，并包含常见错误处理与术语说明。

**预期读者**：学生用户、教师用户、管理员用户、竞赛评审。

### 1.2 范围

本手册覆盖 SparkOrbit 全部用户可见功能，按学生端（学习区/星域/社交/自习/休闲/知识库）、教师端（班级管理/学情/作业/锻造/巡查/沙盘/工单）、管理员端（用户管理/内容管理/用量监控/维护模式）三部分展开。

### 1.3 术语定义

| 术语 | 含义 |
|------|------|
| 星系 (Galaxy) | 一门课程，如"数据结构""计算机网络" |
| 行星 (Planet) | 一个知识点，如"单链表反转""OSI七层模型" |
| 四闸 | 学闸→练闸→讲闸→用闸四级掌握度验证门禁 |
| Mirror | 认知画像对话系统 |
| 星轨领航台 | 系统主界面，以星空隐喻导航 |
| 星库 | 学生学习资源收藏与管理中心 |
| 演武舱 (AlgoVizLab) | 算法可视化练习 |
| 代码舱 (CodeLab) | 在线代码沙箱执行环境 |
| SSE | Server-Sent Events，服务器→客户端流式推送 |
| RAG | 检索增强生成，使用知识库上下文提升回答质量 |

### 2.2 性能说明

| 操作类型 | 预期响应时间 | 说明 |
|----------|-------------|------|
| 页面加载 | < 2s | Vue 3 SPA 懒加载 |
| 常规查询 | < 500ms | FastAPI 异步 + MySQL 索引 |
| AI 文本生成 | 5-30s（SSE 流式） | 第一个 chunk < 3s，持续推送至完成 |
| Seedance 视频生成 | 2-5 分钟 | 异步任务，完成后通知 |
| 数字人虚拟讲解 | 30-60s | 异步任务，生成期间可查看文本内容 |

### 2.3 安全保密

- 三角色（学生/教师/管理员）RBAC 隔离，不同角色可访问的功能区域不同
- 密码使用 PBKDF2-SHA256 哈希存储，登录使用 Token 认证
- 个人数据仅本人与对应教师可见，管理员具有全局访问权限
- 自习督导摄像头数据仅在浏览器端 TensorFlow.js 本地推理，视频流不上传服务器
- 面试仪态评分仅采集关键帧（每轮有帧预算），完整视频流不保留；面试语音经讯飞 IAT 实时转写后不落盘

## 3 运行环境

### 3.1 硬设备

- **客户端**：Windows / macOS / Linux 桌面或笔记本
- **浏览器**：Chrome 90+ / Edge 90+ / Firefox 90+（推荐 Chrome）
- **网络**：需可访问公网（https://wikj.online）或本地 localhost
- 无特殊硬件要求，浏览器支持 WebRTC（自习督导摄像头功能需要）

### 3.2 支持软件

- 无需安装任何客户端软件，纯浏览器访问
- 本地部署需 Docker Desktop（仅部署者操作，详见 D3 操作手册）

### 3.3 数据结构

- 用户数据存储在 MySQL 8.0 中（Docker 部署时位于 `mysql_data` 卷）
- 上传文件存储在 `uploads/`，知识库 Vault 正文存储在 `vaults/<user_id>/`
- AI 生成资源存储在 `GeneratedResource` 表 + 文件系统

## 4 使用过程

### 4.1 安装与初始化

一般用户无需安装。系统已部署于 https://wikj.online，浏览器直接访问即可。本地部署者请参考 D3 操作手册。

### 4.2 学生端操作指南

#### 4.2.1 注册与登录

**操作步骤**：

1. 打开浏览器访问 https://wikj.online
2. 首次使用点击"注册"，填写用户名、密码、角色选择"学生"
3. 填写邀请码加入班级（如无邀请码可先跳过）
4. 已有账号直接输入用户名密码登录
5. 演示账号：用户名 `student001`，密码 `123456`

**预期结果**：登录成功进入星轨领航台首页，顶部可见星系导航栏。

**截图引用**：`d2_student_register_login_01.png` — 登录页面

#### 4.2.2 首次使用引导

**操作步骤**：

1. 首次登录后，系统自动弹出画像对话界面（Mirror）
2. 按系统提示进行自我介绍，建议包含：专业背景、已学课程、学习目标、可用学习时间
3. 系统通过 LLM 推断八维画像（专业背景/前置知识/认知风格/易错倾向/学习目标/时间弹性/模态偏好/动机水平）
4. 缺失维度会以追问形式引导补全，回答越详细采集越快（通常 3-5 轮完成）
5. 画像完成后进入星轨领航台主界面：
   - **中央星空**：展示当前课程星系与行星分布
   - **左侧导航**：学习区 / 星域 / 社交 / 自习 / 休闲
   - **顶部**：课程星系切换、搜索
   - **底部**：问伴学 AI 辅导入口

**预期结果**：画像八维完整，领航台界面正常渲染。

**截图引用**：`d2_student_profile_init_01.png` — 画像对话界面；`d2_student_dashboard_01.png` — 星轨领航台

#### 4.2.3 资源工坊使用

**功能说明**：资源工坊是系统的核心功能模块，支持七类学习资源的智能生成。

**操作步骤**：

1. 在星空中点击一颗行星（知识点），进入行星详情
2. 点击"资源工坊"标签
3. 勾选需要生成的资源类型（可多选）：
   - 文档 (doc) — Markdown 格式知识点详解
   - 思维导图 (mindmap) — Mermaid 格式知识结构图
   - 习题 (quiz) — 含选择/填空/代码/案例分析
   - 阅读材料 (reading) — 拓展阅读与跨学科关联
   - 视频 (media) — Seedance AI 生成教学短视频
   - 课件 (deck) — TTS 自动讲解教学课件，支持 PPTX 导出
   - 代码 (code) — 可运行的示例代码
4. 点击"生成"，观察界面上的 SSE 流式反馈区域
5. 生成过程分阶段展示：
   - **meta 阶段**：显示启动的 Agent 列表
   - **chunk 阶段**：实时打字机效果展示生成内容
   - **quality 阶段**：显示质量评分（准确性/完整性/适应性/可读性）
   - **provenance 阶段**：显示知识来源（教材章节/知识点/生成模型）
   - **done 阶段**：完成提示，显示成功/失败统计
6. 生成完成后，资源自动保存到"星库"，可随时回看

**输入示例**：

| 参数 | 示例值 |
|------|--------|
| 行星 | OSI七层模型 (`osi-model`) |
| 资源类型 | doc + mindmap + quiz |
| 语言偏好 | 中文 |
| 难度 | 中级 |

**输出示例**：见 `docs/evidence/resource_cases.md`（7 类资源质量自评表）。

**截图引用**：`d2_student_resource_doc_01.png` / `d2_student_resource_mindmap_01.png` / `d2_student_resource_quiz_01.png` / `d2_student_resource_reading_01.png` / `d2_student_resource_media_01.png` / `d2_student_resource_deck_01.png` / `d2_student_resource_code_01.png`

#### 4.2.4 行星挑战闯关（四闸）

**功能说明**：每颗行星需要通过学闸→练闸→讲闸→用闸四道门禁才能点亮，形成"学、练、讲、用"完整闭环。

**操作步骤**：

1. 进入行星详情页，点击"开始挑战"
2. **学闸 (ViewGate)**：阅读系统推荐的学习文档，完成后答题
   - 题型：选择题/填空题
   - 通过分数：>=70 分
   - 不通过可重试
3. **练闸 (PracticeGate)**：完成编程练习或实践题目
   - 代码题在代码舱中编写并执行
   - 练习题在线作答
   - 通过分数：>=70 分
4. **讲闸 (ExplainGate)**：用费曼法用自己的话讲解该知识点
   - 系统 AI 评判理解的完整性和准确性
   - 指出理解不到位的部分
   - 通过分数：费曼评判 >=70 分
5. **用闸 (ApplyGate)**：综合应用题或项目实操
   - 综合考察应用能力
   - 通过分数：>=70 分
6. 四闸全部通过后，行星点亮为金色，掌握度 (mastery) >=80%

**记忆衰减机制**：已点亮的行星会随时间衰减，掌握度 <60 时回退到讲闸、<40 时回退到用闸，系统会提示复习。

**预期结果**：每闸通过后状态更新，行星逐步点亮。

**截图引用**：`d2_student_challenge_viewgate_01.png` / `d2_student_challenge_practice_01.png` / `d2_student_challenge_explain_01.png`

#### 4.2.5 苏格拉底/费曼 AI 辅导

**功能说明**：双模式智能辅导——苏格拉底引导式反问 + 费曼讲解式教学。

**操作步骤**：

1. 点击底部"问伴学"按钮，或行星详情页的 Tutor 入口
2. 选择辅导模式：
   - **苏格拉底模式**（默认勾选）：AI 不直接给答案，用反问引导学生推理
   - **费曼模式**：学生用自己的话解释概念，AI 评判理解程度并指出疏漏
3. 输入问题，观察回复是否符合所选模式：
   - 苏格拉底模式首轮回复应为反问/引导
   - 费曼模式应在讲解后评判理解
4. 回答底部显示知识来源（如"高等数学星系 - 导数与微分"）

**输入示例**（苏格拉底模式）：

| 输入 | 期望回复 |
|------|----------|
| "导数怎么学" | 反问：与变化/速度/斜率有什么联系？ |
| "这道题选什么？把答案给我" | 引导：你试过用两个指针同时遍历吗？ |

**证据引用**：见 `docs/evidence/tutor_cases.md`（5 段苏格拉底对话案例）。

**截图引用**：`d2_student_tutor_socratic_01.png` ~ `d2_student_tutor_socratic_05.png`

#### 4.2.6 学习路径查看与调整

**功能说明**：系统根据画像推荐个性化学习路径，评估完成后自动重排。

**操作步骤**：

1. 进入学习区 → 点击"学习路径"面板
2. 查看当前路径步骤：每步含推荐资源和预计耗时
3. 查看推荐理由（如"根据你的视觉型认知风格，推荐视频资源"）
4. 完成评估后，路径自动重排，弱项前置
5. 也可手动点击"重排路径"按钮

**路径数据项**：

| 字段 | 说明 |
|------|------|
| 步骤序号 | 推荐学习顺序 |
| 行星名称 | 知识点 |
| 推荐资源类型 | 文档/视频/代码等 |
| 预计耗时 | 分钟 |
| 推荐理由 | 基于画像维度的匹配说明 |

**证据引用**：见 `docs/evidence/path_cases.md`（3 条 before/after 对比路径案例）。

### 4.8 出错处理与恢复

| 错误现象 | 可能原因 | 处理方式 |
|----------|----------|----------|
| 页面加载失败 | 网络断开、服务器宕机 | 检查网络，刷新页面或稍后重试 |
| 登录失败 | 用户名或密码错误 | 检查输入，确认账户未禁用 |
| 登录过期 | JWT Token 过期 | 重新登录 |
| AI 资源生成失败 | API Key 未配置、额度耗尽 | 联系管理员检查配置，稍后重试 |
| Seedance 视频生成超时 | AI 服务响应慢 | 系统自动降级为文本描述，不影响其他资源 |
| 接口返回 502 | Backend 容器未就绪 | 等待 1-2 分钟后刷新（MySQL 就绪后后端才完整启动） |
| 维护模式拦截 | 管理员开启了维护模式 | 等待维护结束后重试 |
| 挑战提交失败 | 网络波动 | 刷新页面重新提交 |
| 数字人视频加载失败 | 讯飞服务不可用 | 使用文本 Tutor 模式替代 |
